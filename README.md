# SMART-LPG-LEAKAGE-DETECTION-AND-AUTOMATIC-GAS-SHUT-OFF-SYSTEM
Smart LPG Leakage Detection System
1. Introduction
LPG (Liquefied Petroleum Gas) is commonly used in homes, hotels and industries for cooking and heating. Gas leakage can cause fire accidents, explosions and unnecessary fuel wastage. An automatic LPG leakage detection system helps identify leakage early and take immediate action.
2. Working Principle
The system works using an MQ-2 gas sensor connected to an Arduino Uno. The sensor continuously monitors the surrounding air for LPG. When the gas concentration exceeds a predefined threshold, the Arduino detects the leakage condition and activates the safety mechanism.
3. Main Components
- Arduino Uno – Main controlling unit.
- MQ-2 Gas Sensor – Detects LPG leakage.
- Solenoid Valve – Automatically controls gas flow.
- Relay Module – Controls the solenoid valve.
- Buzzer – Provides an audio warning.
- LED – Indicates leakage status.
4. System Operation
1. The MQ-2 sensor monitors the surrounding air.
2. Gas leakage is detected by the sensor.
3. Arduino processes the sensor readings.
4. The buzzer and LED provide alerts.
5. The solenoid valve shuts off the LPG supply.
5. Advantages
- Early detection of LPG leakage.
- Automatic gas supply control.
- Reduces unnecessary fuel wastage.
- Improves household safety.
- Affordable prototype using easily available components.
6. Applications
- Residential kitchens.
- Hotels and restaurants.
- Commercial kitchens.
- LPG storage areas.
- Industrial gas monitoring systems.
7. Conclusion
The Smart LPG Leakage Detection System provides an affordable approach to improving gas safety through real-time monitoring and automatic gas shut-off. It helps reduce LPG wastage, minimizes leakage-related risks and promotes sustainable energy consumption.
